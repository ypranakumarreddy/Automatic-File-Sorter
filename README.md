# Automatic File Sorter

This project is a Python script that automatically sorts files in a specified folder into subfolders based on file type (CSV, images, text, documents, PDFs).

## How it Works

- Scans a target directory for files.
- Creates subfolders for each file type if they don't exist.
- Moves files into their respective subfolders based on extension.

## Skills Demonstrated

- Python file and folder operations (`os`, `shutil`)
- Automation of repetitive tasks

## Usage

1. Set the `path` variable in the script to your target folder.
2. Run the script.
